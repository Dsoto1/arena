    XP per match (server, inside applyResult)

    xp = round( f × K × ( min(CF, 40) + 20·survived + 15·won ) )
  f  = the existing table factor × CPU cut (2 humans ×0.5, 3 ×0.75, 4+ ×1; a CPU-played seat ×0.25)
  K  = 1 Ranked · 0.5 Custom (proposal) · 0 if he fell (a dead gladiator has no next level)
  CF counted ≤ 40 a match (anti-farming; Glory still takes all of it)
Custom XP ≤ 300 a UTC day per gladiator.

    A typical survived Ranked bout ≈ 20 CF + 20 + (a win 1 in 4 ≈ 4) ≈ 44 XP; a win with 23 CF = 58 XP (the mock's tally).

    Results tally (page)

    • Opens when the Online landing shows and last102 is unseen (after the results window, after a reload, on another device). Order: CF → coin → Glory (rank-up flourish) → XP (level-up flourish, last = the climax). ≈ 5 s; click/key skips to the end; Reduce motion / Animations Off = the end state at once; Fast speed has no effect (it is a screen, not the board).
    • Continue → the level-up screen when a point is unspent, else the landing. "Later" keeps the point (it waits on the Domus).
    • Coin goes to the house treasury (v0.92 one treasury). Custom shows "no coin is paid" (as 292's #onr100 says) and half XP.
    • A fall shows his Fate card, what was lost, and the Hall verdict; no XP.

    Anti-abuse

    • XP is computed only on the server from the agreed / verified table row (same path as Glory; the v1.01 verifier logs mismatches). Pages never send XP.
    • Custom farming between friends: half XP, CF counted ≤ 40, table factor (2 humans ×0.5), Custom XP ≤ 300 a day, MIN_HUMANS 2 (no solo-vs-CPU farming), CPU-played seats ×0.25.
    • Level points are spent one at a time with a request id (replays answered once), never during a room/match (the kit's ratings are frozen at the horns).
    • Release: typed name checked on the server; refused while in a room/match (no releasing to dodge a Fate); does not reset the house's leaver count; a released gladiator counts like the fallen for Domus rank only if Hall-worthy (question 5) — so release can never raise a house's rank.
    • No respec (question 2) — a respec would let a house re-tune a gladiator for each event.
